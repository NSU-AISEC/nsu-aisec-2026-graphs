# nsu-aisec-2026-graphs

AI보안융합학과 1기 1학기 과목별 지식 그래프([graphify](https://github.com/Graphify-Labs/graphify)) GitHub Pages 게시용 레포.

원본 강의·과제 자료는 비공개 레포 [NSU-AISEC/nsu-aisec-2026](https://github.com/NSU-AISEC/nsu-aisec-2026)에 있습니다. 이 레포는 그 자료를 분석해 생성한 **그래프 시각화(graph.html)만** 공개로 게시합니다.

- 그래프 안의 노드는 논문 제목·강의 개념·수업 중 언급된 사례 등입니다.
- GitHub Pages: https://nsu-aisec.github.io/nsu-aisec-2026-graphs/
